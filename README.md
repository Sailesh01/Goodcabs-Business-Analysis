# 🚕 Goodcabs Business Analysis

Business intelligence dashboard project focused on operational performance of Goodcabs — a fictional ride-sharing company.

This analysis was built as part of the [Codebasics Resume Project Challenge](https://codebasics.io/challenge/codebasics-resume-project-challenge/16), designed to demonstrate practical data analysis and dashboarding skills relevant to real-world business problems.

📊 Key Focus Areas:
- Trip volume and fare trends
- Passenger satisfaction and repeat rates
- Trip types and city-wise distribution
- Operational metrics like average trip distance and fare per km

📌 Tools Used: Power BI, DAX, Excel  
🔗 Full insights and visuals available on my [portfolio website](https://saileshrana.github.io).
